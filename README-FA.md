# وب‌سایت کلینیک زیبایی نیوا | NIVA Aesthetic Clinic

یک لندینگ‌پیج تک‌صفحه‌ای با HTML، CSS و JavaScript خالص، آماده ویرایش در Visual Studio Code.

## اجرا

1. فایل ZIP را Extract کنید.
2. پوشه `niva-aesthetic-clinic` را در VS Code باز کنید.
3. فایل `index.html` را با مرورگر باز کنید. برای تجربه بهتر حین توسعه، افزونه Live Server در VS Code نیز قابل استفاده است.
4. سایت به نصب Node.js، فریم‌ورک یا اجرای دستور build نیاز ندارد.

## فایل‌ها

- `index.html`: ساختار معنایی، محتوای دو زبانه فارسی و انگلیسی، متادیتای پایه SEO و جایگاه‌های محتوایی.
- `styles.css`: سیستم رنگ، تایپوگرافی، چیدمان ادیتوریال، افکت شیشه‌ای محدود، ریسپانسیو و حالت کاهش حرکت.
- `script.js`: منوی موبایل، تغییر زبان، نمایش تدریجی سکشن‌ها، پارالاکس ملایم و اعتبارسنجی نمایشی فرم.
- `DESIGN.md`: راهنمای تصمیم‌های طراحی و توکن‌ها.

## نکات مهم پیش از انتشار

- **اطلاعات واقعی کلینیک:** متن‌های داخل `[کروشه]`، نشانی، تلفن، ایمیل، ساعت کاری، مدارک متخصصان، متن نظر مراجعان و لینک شبکه‌های اجتماعی باید با اطلاعات واقعی جایگزین شوند.
- **فرم رزرو:** فرم در این نسخه فقط ظاهر و اعتبارسنجی سمت مرورگر دارد؛ اطلاعات را ذخیره یا ارسال نمی‌کند. برای دریافت درخواست‌ها باید به API، ایمیل امن یا سامانه رزرو متصل شود.
- **تصاویر:** عکس‌ها با URL مستقیم از Unsplash بارگذاری می‌شوند؛ برای انتشار تجاری نهایی، مالکیت مجوز هر تصویر را بررسی کنید و ترجیحاً تصاویر دارای مجوز و رضایت مناسب کلینیک را به پوشه محلی `assets` اضافه کرده و URLها را به مسیرهای نسبی تغییر دهید.
- **فونت‌ها:** تیترها با Amiri و پاراگراف‌ها و رابط با Vazirmatn از Google Fonts بارگیری می‌شوند و fallback دارند. برای میزبانی مستقل و کنترل کامل، نسخه دارای مجوز فونت‌ها را در پروژه نگه‌داری کنید.
- **SEO:** پیش از انتشار، عنوان/توضیحات نهایی، دامنه canonical، `og:url`، نقشه سایت، `robots.txt` و اطلاعات ساختاریافته تأییدشده را تکمیل کنید. از افزودن مدرک، نشانی یا ادعای درمانی تأییدنشده خودداری شود.
- **حریم خصوصی:** متن نهایی سیاست حریم خصوصی و نحوه استفاده از اطلاعات باید پیش از فعال‌کردن فرم تأیید شود.

## استقرار در GitHub Pages

فایل `index.html`، `styles.css` و `script.js` را همراه هم در ریشه مخزن قرار دهید و Push کنید. چون مسیرهای این سه فایل نسبی‌اند، نام فایل‌ها و حروف بزرگ/کوچک را تغییر ندهید، مگر اینکه مسیرهای ارجاعی را نیز اصلاح کنید.


## بخش Categories / دسته‌بندی‌ها

بخش تمام‌عرض Categories بعد از «خدمات» اضافه شده است و سه ویدئوی `face`، `beauty tools` و `body` را با نشانی‌های HTTPS اصلی نمایش می‌دهد. این ویدئوها به‌صورت مستقیم از CDN ارائه‌شده بارگذاری می‌شوند؛ برای همین لازم نیست URL نسبی ساخته شود و در GitHub Pages نیز به مسیر زیرشاخه مخزن وابسته نیستند.

- `index.html` در ریشه پروژه قرار دارد.
- فایل‌های `styles.css` و `script.js` با مسیر نسبی از ریشه همان پوشه فراخوانی می‌شوند.
- تصاویر پوستر و سایر تصاویر نمونه فعلاً URL خارجی دارند.
- برای میزبانی ویدئوها داخل خود مخزن، فایل‌ها را در `assets/videos/` بگذارید و مقدار `src` هر ویدئو را به مسیرهایی مانند `assets/videos/face.mp4` عوض کنید. سه فایل ویدئو در این ZIP کپی نشده‌اند چون نشانی‌های منبع خارجی مشخص شده‌اند.

برای GitHub Pages، کل محتویات پوشه `niva-aesthetic-clinic` را در ریشه مخزن یا در پوشه‌ای که Pages از آن منتشر می‌کند قرار دهید؛ اگر پروژه را داخل زیردایرکتوری قرار می‌دهید، برای CSS، JavaScript و فایل‌های محلی از مسیرهای نسبی استفاده کنید.


## چیدمان جدید (براساس تصویر مرجع)

هِرو با تیتر گرادیانی و کارت ناچ‌دار ← کارت‌های خدمات ← آکاردئون «نگاه نیوا» ← تجربه نیوا ← درباره من ← ژورنال ← ردیف ویدئوهای دسته‌ها (دایره، مستطیل گرد، طاق) ← روایت تصویری ← تیم ← نظرات ← پرسش‌های متداول ← فرم مشاوره ← فوتر پنلی. انیمیشن‌های قبلی (ظهور با اسکرول، پارالاکس هیرو، ظهور دسته‌ها، هاور تصاویر و دکمه‌ها) بدون تغییر مانده‌اند. تصاویر کارت‌ها نمونه‌اند و باید با تصاویر اختصاصی کلینیک جایگزین شوند.
